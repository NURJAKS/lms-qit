# 🚀 Инструкция по запуску LMS платформы на Windows

Этот проект подготовлен для максимально простого переноса и запуска на операционной системе Windows.

Мы добавили специальный **умный скрипт автоматической настройки**, который сам подготовит окружение, установит все необходимые зависимости и запустит оба сервиса (Backend и Frontend) в клик!

---

## 🛠️ Системные требования
Для запуска проекта на Windows необходимы две вещи:
1. **Python 3.12+**
2. **Node.js LTS**

> [!TIP]
> **Автоматическая установка:** Если у вас установлена Windows 10/11, наш скрипт `start-windows.bat` попытается установить Python и Node.js автоматически с помощью стандартного установщика **Windows Package Manager (winget)**. Вам останется только подтвердить операцию.

Если вы хотите установить их вручную:
* **Python:** [Скачать Python 3.12+](https://www.python.org/downloads/) *(Обязательно поставьте галочку **"Add python.exe to PATH"** во время установки!)*
* **Node.js:** [Скачать Node.js LTS](https://nodejs.org/)

---

## ⚡ Способ 1: Быстрый запуск через `start-windows.bat` (Рекомендуемый)

Просто распакуйте ZIP-архив в любую папку и дважды кликните по файлу:
👉 **`start-windows.bat`**

### Что сделает скрипт автоматически:
1. Проверит наличие Python и Node.js. Если их нет — предложит установить через `winget`.
2. Создаст виртуальное окружение Python (`.venv`) в папке `backend`.
3. Установит все необходимые Python-зависимости из `requirements.txt`.
4. Создаст конфигурационные `.env`-файлы из примеров (`.env.example`).
5. Инициализирует и заполнит базу данных SQLite (`education.db`) начальными демонстрационными данными (пользователи, курсы, прогресс и т.д.).
6. Установит npm-пакеты для фронтенда.
7. Запустит Backend и Frontend в отдельных удобных окнах консоли.

---

## 🐳 Способ 2: Запуск через Docker (Если установлен Docker Desktop)

Если на вашем компьютере уже установлен и запущен **Docker Desktop**, вы можете запустить проект одной командой.

1. Откройте терминал (PowerShell или CMD) в папке проекта.
2. Выполните команду:
   ```bash
   docker-compose up --build
   ```
В этом случае проект запустится в контейнерах, и вам вообще не потребуется устанавливать Python или Node.js на хост-машину.

## 🌍 Как пользоваться запущенным проектом?

После успешного запуска проекта (любым из способов), откройте ваш браузер по следующим адресам:

* **🖥️ Фронтенд (Сайт платформы):** [http://localhost:3000](http://localhost:3000)
* **🔌 Бэкенд API:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
* **📖 Документация API (Swagger):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 📦 Как создать этот ZIP-архив заново? (Для разработчика)

Если вы изменили код и хотите упаковать проект в чистый ZIP-архив без мусора (без тяжелых папок `.git`, `node_modules`, `.venv`, `.next`), просто запустите в корне проекта команду:
```bash
python create_zip.py
```
Скрипт сгенерирует легкий архив `lms-platform.zip` размером всего ~10-15 МБ, готовый к отправке.
